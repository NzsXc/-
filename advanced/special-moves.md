# スペシャル技

## 演出プレビュー

ホームの「バトルカード・S技プレビュー」、または `battle-preview.html` から12種類のS技を試せる。技を選び、カードをタップして発動する。相手の通常／S技も選択可能。毎回HP7・通常ゲージ10・Sゲージ30から開始し、既存の `free-calculator.js` のversion 3でダメージ・回復・ゲージを計算する。プレビューは対戦への参加、成績やローカルデータの保存を行わない。

実際の対戦と同じ `BattleEffects` を再生する。S技には回転する発動陣、集束する粒子、命中時の多重斬撃、支援の光粒を追加。相殺・反射・ブロックで攻撃が通らない場合、相手への追加斬撃は出さない。Sアンチガードは鎖と南京錠、Sルインは黒い日食・渦・降り注ぐ火の粉で表す。演出時間は既存と同じ1200msで、動きを減らす設定では静止画を表示する。

`node tests/battle-preview.test.cjs` で全12技の発動・再発動、実計算との一致、PC・スマホ・横画面、動きを減らす設定、データ非保存を検証する。Playwrightが必要。

新しいスペシャル対戦は `rulesVersion:3` / `special.version:3`。既存のversion 1対戦・履歴は蓄積のみ、version 2はSブリーチ消費8の挙動を保つ。新しい部屋のHPは10。
S技は通常技のゲージ消費・効果に下表の追加効果が乗る。Sゲージは消費後、ターン＋1、受けたダメージ1につき＋1、チャージ＋1、S技による増加を加えて最大30。ミラーの消費量と表示名はミラー自身のまま。

| 技 | S消費 | 追加効果 |
| --- | ---: | --- |
| Sブリーチ | 12 | 攻撃同士の相殺に、一方的に打ち勝つ |
| Sカウンター | 8 | 反射ダメージ＋1 |
| Sパニッシュ | 8 | 相手がチャージ以外でも基本攻撃力3。通常のチャージ追加ダメージは重ねない |
| Sヒール | 12 | 回復量＋1 |
| Sフォーサイト | 12 | 通常ゲージを追加で＋3。相手のチャージ時は通常効果と合わせて＋6 |
| Sモーメンタム | 8 | 次に使う通常/Sモーメンタムの攻撃力＋1。別行動を挟んでも保持 |
| Sアンチガード | 12 | 次の2ターン、敵の装備技3つとブロックをゲージに関係なく封印。通常効果の即時封印も適用 |
| Sランページ | 12 | Sゲージ＋15 |
| Sエンハンス | 16 | 攻撃力＋1の持続を次の4ターンに更新 |
| Sミラー | 6 | チャージ・アタック・ブロックをまねたとき、通常ゲージ＋2 |
| Sルイン | 6 | 通常の3ターン持続中、相手のチャージ時に通常ゲージも−1。「Sルイン」と表示 |
| Sサイフォン | 8 | 奪うゲージの量+1 |

通常/Sミラーは相手のS追加効果もコピーする。ミラー同士は効果なし。リフレッシュでS封印とSルインも解除できる。攻撃態勢は効果公開後、そのターンのカードに＋1を表示する。

## 公開

新仕様の対応確認は `freeGames/_protocol/advanced/specialMovesV2` と `specialHp10`。未公開なら部屋作成・参加を止める。

先に `firebase-database.rules.json` 全文をRealtime Databaseのルールへ公開してからサイトを更新する。ルールは256KiB以内に収めるため1行のJSON。旧ルールでは新しいスペシャル部屋の作成・参加を止め、更新が必要と表示する。

`tests/upgrade-special-moves-rules.cjs` がS技用ルールと旧対戦の共通計算式を生成する。入力は本変更前のルール（commit `81946d93b93485c544e3d6e216c6e0166637ff60`）。リテラルパスの圧縮は同じ参照先を保つ。スキル受領は既存のAdvanced専用・選択ID一致・ターン一致の書き込み制約で保護される。

## 検証

- `node tests/special-moves.test.cjs`：945組の通常/S技・スキル併用、ゲージ不足、装備制約、2T封印、履歴
- `node tests/advanced-skills.test.cjs`：既存Advanced 2916組
- `node tests/advanced-options.test.cjs`：4種類の設定で作成→参加→対戦→観戦→履歴
- `node tests/special-ui.test.cjs` / `node tests/notice-guide-ui.test.cjs`：PC・スマホ・横画面、切替位置、投票、状態表示
- `FIREBASE_DATABASE_EMULATOR_JAR=/path/to/database.jar node tests/special-emulator.test.cjs`：公式エミュレーターでルールコンパイル、認証付き技送信、状態/Sゲージ同時保存と不正操作拒否

ブラウザーテストは `PLAYWRIGHT_CHROMIUM_EXECUTABLE` でChromiumのパスを指定できる。


HP10と消費12への更新は `tests/upgrade-special-balance-rules.cjs` を本変更前のルール（commit `176b8acce75fc07d7cad9f0cdfffaf8c16c0d65b`）へ適用する。
